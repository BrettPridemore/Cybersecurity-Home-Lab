# Initial Lab Build
A safe isolated practice environment where I can attack a vulnerable machine, implement and use security tools to detect it, collect results, and use mitigations to prevent attacks in the future.

## Objectives

- Deploy VMware Workstation Pro
- Create Kali Linux VM to produce attacks
- Create Metasploitable VM to act as victim
- Create IDS VM to detect malicious traffic and transmit to SIEM
- Create SIEM to gather traffic and centralize information
- Configure isolated network
- Validate VM connectivity

## Tools Used
- VMware
- Kali Linus
- Ubuntu Linux (Suricata, Zeek)
- Metasploitable
- Nmap
- Docker
- Wazuh

## Completed Tasks

- [x] Installed VMware Workstation Pro
